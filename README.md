# Jeopardy Game Project

A fun, interactive Jeopardy-style trivia game built with React. Customize questions and answers by editing the game data file. This is a modern React application with no backend required.

![screenshot](https://github.com/jtba/jeopardy/blob/master/docs/screenshot1.png)

## Getting Started

This application is built with React, Vite, and Bootstrap 5. It's a quick way to have some fun with your team!

### Prerequisites

* Node.js (v16 or higher)
* npm or yarn

### Installing

1. Clone the repository
   ```bash
   git clone https://github.com/jtba/jeopardy.git
   cd jeopardy
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Customize questions (optional)
   - Edit the game data in `/src/data/gameData.js`
   - Modify categories, questions, answers, and team names

4. Run the development server
   ```bash
   npm run dev
   ```

5. Build for production
   ```bash
   npm run build
   ```
